# 護理安全訓練遊戲

離線單檔訓練遊戲：用 **貪食蛇問答** 或 **飛翔小鳥問答** 練習病房流程。題目來自 M10→C9 現行指引、實用交更清單，以及 C7 專項（C7＝另一病房，唔好當 C9 日常 SOP）。全部為虛構訓練情境，不是考試認證，也不是醫療建議。

## 如何開始

1. 使用 **Google Chrome**。
2. 雙擊本資料夾中的 `game.html`。
3. 遊戲會以 `file://` 開啟。

不需要安裝、不需要擴充功能、不需要網路、不需要啟動伺服器。所有 CSS、JavaScript 同題目都寫在同一個 HTML 檔內。

## 玩法

主畫面一打開就揀 **貪食蛇** 或 **飛翔小鳥**（大卡片，適合 iPad）。

- **貪食蛇問答**：闊螢幕（iPad、橫向）左邊題目同 A／B／C／D 全文，右邊棋盤同方向鍵。iPhone 直向會上下排，方向鍵夠大。撞到食物任何一格都算吃到。
- **飛翔小鳥問答**：手指或滑鼠**點畫面**、或撳「拍翅」，令小鳥向上飛；飛入標示 **A／B／C／D** 的閘門即作答。適合 iPhone／iPad。
- 任何時候（作答中、暫停、睇解釋、結果頁）撳右上 **返回主畫面／轉遊戲**，返去揀另一種玩法。

共通規則：

- 答錯不會結束遊戲；看完解釋同學習重點後進入下一題。
- 可用暫停與靜音。
- 分數只是學習回饋，不是績效考核。

## 題目來源

題目覆蓋：

- C7 專項 checklist（身份、電話、探病、收症／rota、本位、搬遷過渡）
- M10→C9 現行有效指引
- M10→C9 實用交更／新人 checklist

常改項目（admission rota、ceiling、感染名單）以當期 HA Teams／email／IC 為準。

## 注意

本遊戲只供訓練用途，實際工作請依照部門指引。不收集、不上傳任何個人資料。
