# 護理安全訓練遊戲

離線訓練遊戲：用 **貪食蛇問答**、**飛翔小鳥問答** 或 **病房探索** 練習病房流程。題目來自 M10→C9 現行指引、實用交更清單，以及 C7 專項（C7＝另一病房，唔好當 C9 日常 SOP）。全部為虛構訓練情境，不是考試認證，也不是醫療建議。

## 如何開始

1. 使用 **Google Chrome**。
2. 雙擊本資料夾中的 `game.html`。
3. 遊戲會以 `file://` 開啟。

不需要安裝、不需要擴充功能、不需要網路、不需要啟動伺服器，亦**唔使密碼**。請保留 `game.html`、`ward-shell.js`、`ward-map.js`、`ward.bundle.js` 及 `vendor/THREE-LICENSE.txt`，並保持資料夾結構。雙擊 `game.html` 即可，唔好只抄走 HTML。如果某個網頁叫你入密碼，嗰個係預覽網站的鎖，唔係遊戲。

## 玩法

主畫面一打開就揀 **貪食蛇**、**飛翔小鳥** 或 **病房探索**（大卡片，適合 iPhone／iPad）。

- **貪食蛇問答**：闊螢幕（iPad、橫向）左邊題目同 A／B／C／D 全文，右邊棋盤同方向鍵。iPhone 直向會上下排，方向鍵夠大。撞到食物任何一格都算吃到。
- **飛翔小鳥問答**：手指或滑鼠**點畫面**、或撳「拍翅」，令小鳥向上飛；飛入標示 **A／B／C／D** 的閘門即作答。適合 iPhone／iPad。
- **病房探索**：探索虛構的 C 座訓練平面，房間位置和大小參考圖片作大約調整，並非官方圖則。探病室連接升降機大堂及病房走廊；六人病房各有六張床，房間和花園設有相應設施。病房有三名護士角色，每個任務亦有一名虛構病人；可走近角色撳 **A** 交談或觀察，交談不是完成任務的必要步驟。左下搖桿拖去邊就行去邊，越拖越快；**A／左** 係畫面左，**D／右** 係畫面右，**W／S** 係畫面上下。畫面 **A** 互動（鍵盤 Z 或 Enter），**B** 取消或睇任務（鍵盤 X、B 或 Esc）。左下角圓形小地圖可撳大，放大後可查看房間編號清單。行一會遇到急救、收症或躁動約束。答錯唔會結束遊戲。
- 任何時候（作答中、暫停、睇解釋、結果頁）撳右上 **返回主畫面／轉遊戲**，返去揀另一種玩法。

共通規則：

- 答錯不會結束遊戲；看完解釋同學習重點後進入下一題。
- 可用暫停與靜音。
- 分數只是學習回饋，不是績效考核。

## 開發及測試

玩家不需要以下步驟。修改病房原始碼需要 Node.js 18 或以上；首次安裝套件或 Playwright 瀏覽器可能需要網絡。

```sh
npm ci
npm run build:ward
npm run test:ward
```

病房程式使用 Three.js ES Module 開發，構建後的 `ward.bundle.js` 是可由本機同步載入的檔案，遊玩時不會連接 CDN。修改 `ward.js` 後必須重新構建並一併交付 bundle。測試會優先使用已安裝的 Chrome；亦可設定 `CHROME_PATH`，或先執行 `npx playwright install chromium` 安裝測試瀏覽器。Three.js 授權文字位於 `vendor/THREE-LICENSE.txt`。

## 題目來源

題目覆蓋：

- C7 專項 checklist（身份、電話、探病、收症／rota、本位、搬遷過渡）
- M10→C9 現行有效指引
- M10→C9 實用交更／新人 checklist

常改項目（admission rota、ceiling、感染名單）以當期 HA Teams／email／IC 為準。
