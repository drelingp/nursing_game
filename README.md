# 護理安全訓練遊戲

以貪食蛇方式練習病房與門診常見的護理安全題目。內容為虛構訓練情境，不是考試認證，也不是醫療建議。

## 如何開始

1. 使用 **Google Chrome**。
2. 雙擊本資料夾中的 `game.html`。
3. 遊戲會以 `file://` 開啟。

不需要安裝、不需要擴充功能、不需要網路、不需要啟動伺服器。

## 操作

- 鍵盤方向鍵，或畫面上的方向鍵，控制蛇移動。
- 吃到標示 **A / B / C / D** 的答案食物，即選擇該選項。
- 答錯不會結束遊戲；看完解釋後可繼續下一題。
- 可用暫停與靜音按鈕。

## 注意

本遊戲只供訓練用途，實際工作請依照部門指引。分數只是學習回饋，不是績效考核。
